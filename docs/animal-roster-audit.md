# รายชื่อสัตว์และสิ่งที่ยังไม่ครบ

## หลักฐานปัจจุบัน

ตรวจจาก `src/content/forms.js`, `src/systems/life-route.js`, `src/prototypes/animal-catalog.js`, `src/render/forms-sprites.js`, `src/render/animal-vectors.js` และ `src/game/`

พบข้อมูลร่าง **28 แบบ = สัตว์ 25 ชนิด + มนุษย์ อสุร เทวดา** ข้อมูลทุกแบบตั้ง `rebirth: true` แต่ธงนี้เพียงอย่างเดียวไม่ได้รับรองว่าจะถูกเลือกเข้าด่านจริง ต้องอยู่ในรายชื่อของบทและผ่านเงื่อนไขแผนที่ด้วย

สถานะในตารางหมายถึง “พบโค้ดรองรับ” ไม่ใช่รับรองว่าเล่นครบทุกบทและทุกอุปกรณ์แล้ว

**อัปเดต: ตารางความพร้อมจริงถูกทำเป็นเทสต์แล้ว** — `tests/roster.test.mjs` ตรวจทั้ง 28 ร่างจากข้อมูลจริงแบบไดนามิก (โครงร่าง/ภาพ/เกิด/เดิน/เป้าหมาย/ใช้ท่า/เซฟ-โหลด) และพิมพ์ตารางออกมาทาง log · ผลรันล่าสุด: 25 ร่างเกิดได้จริง (มนุษย์เริ่มเรื่อง · อสุร/เทวดายังเป็นร่างที่พบ ไม่ใช่ร่างเกิด) · เป้าหมายที่ถูก *การกระทำ* กั้น (หมูป่า · ช้าง) พิสูจน์ด้วย site proof ของตัวเอง · ถนนของทุกภพเดินได้ทุก seed ที่สุ่มตรวจ · เซฟ-โหลดคืนทั้งร่าง ชาติ และสิ่งที่โลกจำ (สะพาน/ดินที่ดุน/แปลงที่ปล่อย)

เทสต์นี้ตรวจ **ทุกภพ** ต่อร่าง (7 ภพ × 2 เมล็ด) เพราะกรรมเป็นตัวเลือกภพ ไม่ใช่ตัวร่าง — การตรวจแบบเดิม (เฉพาะภพที่ร่างนั้นดูเหมือนจะไป) พลาดเคส “กระรอกในภพนครอสุร” ที่ผนังลานไปปิดแคชเมล็ดไว้ · มี `tests/sites.test.mjs` กันระดับแผนที่อีกชั้น

เทสต์นี้ยังกันเคสชื่อชนิดเป้าหมายชนกัน (บทเรียนจาก `roost` ของนกฮูก/ค้างคาว และ `home` ของแมว/ปู): **ทุกชนิดที่จบชีวิตต้องถูกประกาศในโมดูลของสัตว์ตัวเดียวเท่านั้น** — ตรวจโดยอ่านเฉพาะ `kind: '...'` และตัดคอมเมนต์ออกก่อน

รายการต่อไปนี้เป็นข้อเสนอ ไม่มีภาพหรือกลไกใหม่จากงานรอบนี้ ไม่ได้ตั้งเป้าว่าต้องใส่สัตว์ทุกชนิดในโลก

| ชนิด | ความสามารถที่ต่างจากของเดิม | สถานการณ์สนุก | ลำดับ |
|---|---|---|---|
| แมงมุม | ขึงใยเชื่อมจุดยึด | สร้างสะพานให้ตัวเล็ก โดยไม่ปิดทางผู้อื่น | P1 |
| หิ่งห้อย | ส่งแสงเป็นจังหวะ | สื่อสารกับฝูงและนำทางในหมอก | P1 |
| ด้วง | ผลักวัตถุด้วยแรงและทิศ | ร่วมกับมดขนเมล็ดใหญ่ข้ามร่อง | P1 |
| ไก่ป่า | เขี่ยพื้นและเตือนฝูง | หาอาหารพร้อมเฝ้าลูกเล็ก | P2 |
| เป็ด | เดินและลอยน้ำเป็นกลุ่ม | พาฝูงผ่านกระแสและจุดพัก | P2 |
| กิ้งก่า | พรางตัวตามพื้นผิว | เลือกหยุดรอแทนวิ่งผ่านพื้นที่เฝ้าระวัง | P2 |
| แมลงปอ | บินหยุดนิ่งและเปลี่ยนทิศเร็ว | แตะจุดสัญญาณเหนือผิวน้ำ | P2 |

| จระเข้ | ดำน้ำและลอยนิ่ง | เปิดเส้นทางน้ำโดยไม่ทำฝูงแตกตื่น | P3 |

## คำว่า “ครบหนึ่งตัว” ต้องมีอะไร

- ภาพจากโค้ดที่อ่านชนิดได้ชัดทั้งหันซ้ายและขวา
- ท่าพัก เคลื่อนที่ ใช้ความสามารถ รับผล และเกิดใหม่
- ความสามารถเปลี่ยนทางแก้โจทย์จริง ไม่ใช่แค่เอฟเฟกต์
- จุดเกิด จุดพัก เป้าหมาย และแผนที่ที่ร่างนั้นเข้าถึงได้
- บทฝึกสั้นที่กดทดลองได้ และคำใบ้เมื่อไม่เข้าใจ
- ปุ่มคีย์บอร์ดและสัมผัสครบ ข้อความไทย–ลาว–อังกฤษ
- เซฟ/โหลดระหว่างใช้ท่าและเปลี่ยนชาติได้
- ตรวจไม่ติดทางตัน ไม่จบชาติซ้ำ และไม่ต้องฟาร์มเพื่อออกจากร่าง
