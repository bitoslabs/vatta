# แนวภาพตัวละครปัจจุบัน

ตามความต้องการของผู้ใช้: ใช้ภาพเรียบง่ายแบบเดิม วาดเส้นและรูปทรงด้วยโค้ด Canvas ไม่ใช้ ImageGen สำหรับตัวละคร

หน้าทดลอง character-lab.html ใช้ forms-sprites.js สำหรับร่างเดิม และ animal-vectors.js สำหรับสัตว์เพิ่ม 8 ตัว ทั้ง 18 ร่างไม่โหลดภาพ PNG หรือ atlas แอนิเมชันขยับด้วยเวลาและสถานะการเดิน/ใช้ท่า

ไฟล์ภาพที่เคยสร้างเก็บไว้เป็นประวัติ แต่ไม่ได้เรียกใช้ในหน้าทดลองปัจจุบัน

## เชื่อมเข้าธรรมชาติหลักแล้ว (รอบบทไส้เดือน)

สัตว์เพิ่ม 8 ตัวถูกย้ายจาก "หน้าทดลองเท่านั้น" เข้ามาเป็น **ร่างของเกมหลัก** ใน `content/forms.js` โดยใช้ id ชุดเดียวกับ `prototypes/animal-catalog.js` ทุกตัวมีข้อมูลร่าง (ความเร็ว/สายตา/ความกลัว/ความสามารถ) และรูปแบบการวาดยังมี **แหล่งเดียว** คือ `render/animal-vectors.js` — `render/forms-sprites.js` เรียกตัววาดเดิมนี้สำหรับร่างสัตว์ใหม่ แทนการลอกรูปใหม่ ทำให้ร่างเดียวกันหน้าตาเหมือนกันทั้งในห้องทดลองและบนถนนในเกม (เงา ยกตัว แสงที่อก ยังเป็นของ `drawFormBody` เหมือนร่างอื่นทุกประการ)

สถานะการเล่น: **ไส้เดือน** เล่นได้จริงในวงจรเกิดใหม่ (มีแผนที่โพรงใต้รากและเป้าหมายของตัวเอง — ดู docs/animal-lives-story.md) ส่วน มด กบ งู กระต่าย ช้าง เสือ นกฮูก มีข้อมูลและภาพครบแต่ยัง `rebirth: false` จนกว่าจะมีบทและแผนที่รองรับ โดย `systems/life-route.js` กรองด้วย `maps` ของร่างนั้น ไม่ให้ร่างใดเกิดบนแผนที่ที่ไปถึงเป้าหมายไม่ได้

lab-only ยังไม่มีระบบชน ขนวัตถุจริง หรือศัตรูตรวจจับของตัวเอง — สิ่งเหล่านี้ใช้ระบบกลางของเกมเมื่อร่างนั้นเข้าสู่วงจรเกิดใหม่
