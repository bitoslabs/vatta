# วัฏฏะ — เอกสารขยายระบบสัตว์และการเกิดใหม่

เอกสารชุดนี้แยก **สถานะที่ตรวจพบในโค้ด** ออกจาก **ข้อเสนอสำหรับพัฒนาต่อ** ชัดเจน ใช้ภาพเส้นและรูปทรง Canvas ตามความต้องการผู้เล่น ไม่ใช้ ImageGen

## อ่านตามลำดับ

1. [รายชื่อสัตว์และงานที่ยังขาด](animal-roster-audit.md) — มีอะไรแล้ว อะไรยังไม่ครบ และควรเพิ่มอะไร
2. [ดวงจิต การตาย และเอฟเฟกต์เกิดใหม่](rebirth-effects.md) — ภาพ เสียง เวลา และการควบคุม
3. [สุ่มเกิดและเลือกเกิด](rebirth-modes.md) — กฎเลือกตัวละคร ข้อมูลเซฟ และกรณีผิดพลาด
4. [ปฏิสัมพันธ์และความสนุก](player-interactions.md) — เหตุการณ์ กลไก และตัวอย่างเล่นหนึ่งชาติ
5. [แผนผลิตและเกณฑ์รับงาน](next-production-plan.md) — ทำทีละส่วนและตรวจว่าเล่นได้จริง

อ่านร่วมกับ [โครงเรื่องข้ามชาติ](animal-lives-story.md) และ [แนวภาพตัวละคร](character-art-direction.md)

## ทิศทางที่แนะนำ

ใช้ **สุ่มร่างจากเงื่อนไขด่านเป็นโหมดเนื้อเรื่องเริ่มต้น** และมี **เลือกจาก 3 ร่าง** เป็นทางเลือกก่อนเริ่มการเดินทาง ส่วนเลือกได้ทุกตัวใช้ในโหมดสำรวจ ผู้เล่นควรเห็นผลจากชาติเดิมใน 1–2 ชาติถัดไป และได้ตัดสินใจผ่านการเล่น ไม่ใช่อ่านคำถามอย่างเดียว

สิ่งที่ควรทำก่อนเพิ่มสัตว์จำนวนมากคือเชื่อมวงจรเล็กให้ครบ: จบด่าน → เห็นผลที่ทำไว้ → เปลี่ยนร่าง → พบทางแก้ปัญหาใหม่ → พบผลจากชาติก่อนอีกครั้ง

## ขอบเขตงานรอบนี้

ตรวจรายการจากไฟล์ข้อมูลร่าง เส้นทางเกิดใหม่ ตัววาด และโมดูลการเล่น แล้วจัดทำเอกสารออกแบบชุดนี้ ยังไม่ได้เพิ่มเมนูสุ่ม/เลือกเกิดหรือชุดเอฟเฟกต์ใหม่ลงเกม และไม่ได้ทดสอบทุกสัตว์ครบทุกบทในรอบนี้
