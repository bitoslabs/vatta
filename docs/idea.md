เข้าใจโครงทั้งหมดครับ ผมจะสร้าง **ต้นแบบที่เล่นจบได้จริง 1 บทเต็ม** ตามดีไซน์ของคุณ คือบท "ป่าเสียงเรียก" ที่ครบทั้ง 6 สถานะ: **ออกจากวัด → ผี(ผีหลง)ไล่ → ตั้งสติระหว่างวิ่ง → เข้าศาลา → นั่งสมาธิ(minigame หายใจ + สิ่งรบกวน) → คำถามธรรมะที่โลกตอบสนอง → ปลดปล่อย → เดินกลับวัดยามรุ่งสาง**

ทุกกลไกที่คุณออกแบบ ผมใส่เป็น gameplay จริง ไม่ใช่ข้อความ:
- ยิ่งตื่น (Shift วิ่ง) ผียิ่งเร็ว / Space ค้าง = ตั้งสติ: ตัวช้าลงแต่ผีสะดุด ทางหลอกหาย และ **รอยเท้าจริงเรืองแสงขึ้น**
- ทางแยกหลอก (ประตูแสง) จะโผล่เฉพาะตอน Fear สูง เดินเข้าไป = วนกลับจุดเดิม
- สมาธิ: กดค้าง = หายใจเข้า ปล่อย = หายใจออก ให้ตรงจังหวะ มี "สิ่งรบกวน" โผล่ล่อให้กด X ไล่ — **ถ้าไล่ สมาธิตกและมันยิ่งมา ถ้าปล่อยผ่าน มันจางเอง**
- คำถาม "สิ่งที่เรารักต้องอยู่กับเราตลอดไปหรือไม่?" ไม่มีคำตอบผิดถูก แต่ละทางเลือกให้ฉากตอบสนองต่างกัน


## สิ่งที่ implement จากดีไซน์ของคุณ

**ระบบ "สติระหว่างวิ่งหนี" (ข้อ 10) — Signature mechanic จริงตามที่คุณตั้งใจ:**
- `Fear` สูง → ผี (ผีหลง) เร็วกว่าความเร็ววิ่งเรา, มุมมองแคบลง, เสียงหัวใจถี่ขึ้น, และ**ประตูแสงหลอกโผล่ตามกฎของมัน** (ยิ่งกลัว ยิ่งเห็นทางหลอกน่าเดิน)
- กด `SPACE` ค้าง → ตัวเองช้าลง แต่ผีสะดุด 1 วินาที แล้วช้าลงมาก ถ้าค้างต่อเนื่อง 2.8 วิ ผีจะถอยจางไป — ผู้เล่นได้สัมผัส tension "วิ่งเพื่อรอด หรือช้าลงเพื่อมีสติ" ด้วยตัวเอง
- ทางจริงมี**รอยเท้าเรืองแสง**ที่ค่อยๆ ชัดเมื่อจิตนิ่ง และเสียง "«มานี่ลูก…»" มาจากทิศของประตูหลอกจริง ๆ (มี stereo pan)
- หลงเข้าประตูแสง = วนกลับจุดแยกเดิม + Fear เพิ่ม + ผีบีบเข้ามา — ตามที่คุณเขียนไว้ว่า "ถ้าหนีต่อไปเรื่อยๆ จะวนกลับจุดเดิม"
- ถูกผีจับไม่ตาย แต่ "ความกลัวกลืนกิน" แล้วเกิดใหม่ที่เช็คพอยต์ — ไม่มีความตายในเกมธรรมะ

**สมาธิ (ข้อ 3):** กดค้าง = หายใจเข้า ปล่อย = หายใจออก ต้องตรงเส้นประ มีสิ่งรบกวนโผล่ล่อให้กด `X` ไล่ — **ไล่ = สมาธิตกและสิ่งรบกวนมาถี่ขึ้น, เฉยและหายใจต่อ = มันจางไปเองและเราได้โบนัส** นี่คือบทเรียนกิเลสในรูป mechanic ล้วน ๆ

**คำถามธรรมะ (ข้อ 4-5):** ไม่มีกรอบบอก "ถูก/ผิด" — ตอบว่า "ต้องอยู่ตลอดไป" โลกตอบกลับเป็นฉากเย็นเฉียบ มือที่กำแน่น แล้วเสียงแม่ถามกลับ ก่อนให้เลือกใหม่

**อริยสัจ 4 เป็นโครงด่าน (ข้อ 6):** ทุกข์ (ถูกไล่) → สมุทัย (รู้ว่าผีคือการยึดของแม่-เราเอง) → นิโรธ (ฉากปลดปล่อย) → มรรค (เดินกลับด้วยสติตอนรุ่งสาง)

**ทิศทางต่อยอดที่พร้อมโครงนี้:** เพิ่มผีอีก 4 ตัว (โกรธ/โลภ/ยึดติด — แค่เปลี่ยนกฎ 1 ฟังก์ชัน `updateGhost`), ระบบจำพฤติกรรมแทนคะแนนกรรม (บันทึก action log แล้วดึงกลับมาเป็นเหตุการณ์), และบท 2-6 ต่อด้วย palette/กฎใหม่ต่อกิเลส
