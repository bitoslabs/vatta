# ระบบกรรม — บุญ/บาป · กุศล/อกุศล · วิบาก

> ตามคำสอนในพระไตรปิฎก: **กรรม = เจตนา** (cetanā) — "เจตนาเป็นกรรม"
> เกมจึงไม่นับ "แต้ม" เปล่า ๆ แต่บันทึก **เจตนา + มูลเหตุ + วิบาก**

## 1. สามชั้นของกรรมในเกม

| ชั้น | ความหมาย | เก็บที่ |
|---|---|---|
| **มูล (mūla)** | รากของจิต — กุศลมูล / อกุศลมูล | `karma.roots` |
| **เจตนา** | action ที่ผู้เล่นทำ (ทาน, เมตตา, ตอบโต้…) | `karma.actions[]` |
| **วิบาก (vipāka)** | บุญ / บาป ที่สุกงอม + อนุสัยที่ถูก reinforce | `karma.merit`, `karma.demerit`, `karma.tendencies` |

### มูล 6

| อกุศลมูล 3 |  | กุศลมูล 3 |  |
|---|---|---|---|
| โลภะ | อยากได้ | อโลภะ | ไม่โลภ เสียสละ |
| โทสะ | โกรธ ขัดเคือง | อโทสะ | ไม่โกรธ มีเมตตา |
| โมหะ | หลง ไม่รู้จริง | อโมหะ | ไม่หลง มีปัญญา |

## 2. ตารางกรรม (`content/karma-actions.js`)

| id | ชื่อธรรม | มูล | บุญ | บาป | อนุสัย |
|---|---|---|---|---|---|
| `give` | ทาน | อโลภะ | +8 | | generosity +2, mettā +1 |
| `precept` | ศีล | อโมหะ | +6 | | sati +1, generosity +1 |
| `meditate` | ภาวนา/สมาธิ | อโมหะ | +10 | | concentration +2, sati +2 |
| `mindful` | สติ | อโมหะ | +6 | | sati +2 |
| `compassion` | เมตตา | อโทสะ | +9 | | mettā +3 |
| `letgo` | ปล่อยวาง/จาคะ | อโลภะ | +14 | | mettā +2, **clinging −3**, concentration +1 |
| `harm` | ปาณาติบาต/โทสะ | โทสะ | | −12 | anger +3 |
| `steal` | อทินนาทาน/โลภะ | โลภะ | | −10 | greed +3 |
| `lie` | มุสาวาท/โมหะ | โมหะ | | −8 | delusion +2 |
| `cling` | อุปาทาน | โลภะ | | −7 | clinging +3 |
| `panic` | โมหะ/ตื่นตระหนก | โมหะ | | −3 | delusion +1 |

`letgo` มีค่าน้ำหนักอนุสัยติดลบ เพราะการปล่อยวาง **ลด** อุปาทาน (ไม่ใช่แค่เพิ่มบุญ)

## 3. จุดที่เกมบันทึกกรรม (ปัจจุบัน)

| เหตุการณ์ | action | บท |
|---|---|---|
| ตั้งสติจนผีสลาย (`ghost:pacified = mind`) | `mindful` / `compassion` | 1 / 2 |
| นั่งภาวนาจบ | `meditate` | 1 |
| คำตอบ "รักได้โดยไม่ต้องกำไว้" | `letgo` | 1 |
| คำตอบ "ต้องกำไว้" | `cling` | 1 |
| ถูกความกลัวกลืนกิน | `panic` | ทั้งคู่ |
| ตอบโต้ผีโทสะ (E) | `harm` | 2 |
| คำตอบ "เห็นว่าเขาก็ทุกข์" | `compassion` | 2 |
| คำตอบ "ตอบโทสะด้วยโทสะ" | `harm` | 2 |

## 4. การให้ผล (rebirth) — `systems/rebirth.js`

```
concentration ≥ 10 และ อกุศล ≤ 4   → อรูปภูมิ (4 ชั้น ตามระดับฌาน)
concentration ≥ 7  และ อกุศล ≤ 6   → รูปภูมิ (16 ชั้น)
บาป ≥ บุญ และ (อกุศล ≥ 8 หรือ บาป−บุญ ≥ 10)
                                   → อบายภูมิ ตามอนุสัยที่แรงสุด
                                       โทสะ→นรก · โลภะ→เปรต · โมหะ→ติรัจฉาน · อุปาทาน→อสุรกาย
บุญสุทธิ ≥ 14                      → กามาวจรสวรรค์ 6 ชั้น (ไล่ตามบุญสุทธิ)
อื่น ๆ                             → มนุษย์
```

> **หมายเหตุ:** เป็นนามธรรมเชิงเกมของหลักกรรม ไม่ใช่การพยากรณ์คติที่แท้จริง
> จุดสำคัญที่รักษาไว้: **เจตนาและมูลเหตุสำคัญกว่าคะแนน** — โทสะที่แรงพาไปอบายได้แม้ทำบุญอื่นมาบ้าง

## 5. API

```js
import { recordKarma, getKarma, activeRoots } from '../systems/karma.js';
import { resolveRebirth } from '../systems/rebirth.js';

recordKarma('compassion');            // +9 บุญ, อโทสะ, เมตตา +3
const k = getKarma();                 // { merit, demerit, kusala, akusala, roots, tendencies, actions }
resolveRebirth(k);                    // { realmId:'tusita', reasonKey:'rebirth.reason.merit' }
```

กรรม **สะสมข้ามบท** (saṃsāra) — ไม่รีเซ็ตตอน `loadChapter` รีเซ็ตก็ต่อเมื่อโหลดหน้าใหม่
