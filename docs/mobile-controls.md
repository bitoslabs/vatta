# การเล่นบนมือถือ

บนอุปกรณ์ที่มีการสัมผัส (`pointer: coarse`) เกมแสดงวงควบคุมด้านซ้ายและปุ่ม **วิ่ง**, **สติ**, **โต้ตอบ** ด้านขวา หน้าแรกจะแสดงคำอธิบายการสัมผัสแทนปุ่มคีย์บอร์ด จอยเริ่มตรงจุดที่แตะในพื้นที่ซ้าย แล้วลากเพื่อกำหนดทิศทาง หลังลากเกินระยะกันมือสั่น 12 พิกเซล การเดินจะเร็วเต็มระดับเดียวกับปุ่ม WASD; กดวิ่งค้างพร้อมลากเพื่อเร่ง กดสติค้างจะเดินช้าลงโดยตั้งใจ ปุ่มโต้ตอบใช้คุย/ทำสิ่งใกล้ตัวและเลื่อนบทสนทนาได้ ปุ่ม **☰** เปิดเมนูช่วยเหลือ/ตั้งค่าระหว่างเล่น และปล่อยการเคลื่อนที่ที่กดค้างอยู่ เมื่อร่างค้างคาวหรือร่างที่สืบทอดเสียงสะท้อนใช้ความสามารถได้ จะมีปุ่ม **สะท้อน** เพิ่มขึ้น

ความเร็วพื้นฐานของร่างมนุษย์คือเดิน 150 และวิ่ง 240 หน่วยโลกต่อวินาที ก่อนคูณผลของทางเดิน (นอกทาง ×0.7), ภูมิ, ร่าง และพื้นดิน โคลนหรือร่างบางชนิดจึงอาจยังช้ากว่าถนน แม้จอยให้ความเร็วเต็มแล้ว ความเร็วนี้มาจาก `src/entities/player.js` และ `src/core/constants.js`; จอยและปุ่มวิ่งอยู่ใน `src/ui/touch.js`

เมื่อเข้าหน้าสมาธิ ปุ่ม **กดค้าง — หายใจเข้า** รับการกดค้างและปล่อยนิ้วจริง แตะการ์ดสิ่งรบกวนเพื่อไล่ได้เหมือนปุ่ม X การไล่มีผลต่อคะแนนสมาธิตามกติกาเดิม เมื่อสัมผัสถูกยกเลิก ออกจากหน้า หรือย้ายแอป ปุ่มที่กดค้างและจอยจะปล่อยเองเพื่อไม่ให้เดิน/วิ่ง/หายใจค้าง

## ตรวจสอบ

รัน `npm test -- touch` เพื่อตรวจความเร็วจากจอย การแตะหลายจุด ปุ่มสะท้อน/เมนู และการปล่อยปุ่ม จากนั้นรัน `npm run build:check` และเปิดเกมใน DevTools ด้วยการจำลอง **touch** ที่ขนาด 390×844 และ 844×390: วงจอยควรอยู่ตรงนิ้ว ปุ่มไม่โดนขอบจอหรือทับกัน ทดลองลากจอยพร้อมกดวิ่ง, ปล่อยนิ้วกลางทาง, กดโต้ตอบ, และเล่นหน้าสมาธิบนอุปกรณ์จริงก่อนเผยแพร่
