# แผนผลิตต่อ — ทำให้วงจรชีวิตครบก่อนเพิ่มจำนวน

## ลำดับแนะนำ

| ชุดงาน | สิ่งส่งมอบ | ผ่านเมื่อ |
|---|---|---|
| 1 ตรวจร่างปัจจุบัน | ตารางความพร้อมจริงของ 28 ร่างและ smoke test ต่อร่าง | เกิด เดิน ใช้ท่า ไปถึงเป้าหมาย และโหลดต่อได้ |
| 2 เปลี่ยนชาติ | เอฟเฟกต์แสงหนึ่งแบบ จบชีวิตครั้งเดียว และ pending transition ในเซฟ | ข้าม/ปิดหน้า/โหลดทุกช่วงไม่ซ้ำชาติ |
| 3 สุ่มเกิด | seeded RNG + eligibility ต่อด่าน + หน้าแสดงผล | ร่างทุกผลมีทางไปจบ และโหลดไม่เปลี่ยนผล |
| 4 เลือกเกิด | การ์ดสูงสุด 3 ร่าง พร้อมเปรียบเทียบความสามารถ | ไม่มี timer เลือกแทน และผลยืนยันคงอยู่ |
| 5 ความทรงจำที่เล่นได้ | เมล็ด–ราก–สะพานหนึ่งสายเรื่อง | ผู้เล่นเห็นและใช้ผลจากชาติที่แล้วได้จริง |
| 6 เพื่อนร่วมทาง | NPC หนึ่งชนิด ส่งเสียง/รอ/ช่วยได้ | ตอบสนองชัด ไม่ติดผู้เล่นหรือกีดทาง |
| 7 สัตว์ใหม่ | เริ่มแมงมุมหรือหิ่งห้อยเพียงหนึ่งชนิด | เพิ่มวิธีแก้โจทย์ที่ร่างเดิมไม่มี |

ลำดับนี้เป็นข้อเสนอ ไม่ใช่ประมาณเวลาส่งงาน ทั้งหมดใช้ภาพจากโค้ด

## ตัวอย่างฉบับทดลองที่ครบวงจร

บทมนุษย์ทำทางให้น้ำ → บทไส้เดือนดูแลราก → จบบทมีแสงและความทรงจำ → เลือกสุ่มหรือรับสามร่างตามโหมด → เกิดเป็นมด/กบ/กระต่ายในด่านที่ตรวจแล้ว → พบต้นไม้จากรากเดิม → ใช้ความสามารถพาเพื่อนถึงจุดพัก

ขอบเขตฉบับนี้: 3–4 ชาติ, จุดความทรงจำหนึ่งจุด, เพื่อนหนึ่งตัว, วิธีเกิดสองโหมด และปลายทางทดลองหนึ่งฉาก ไม่ต้องรอผลิตสัตว์ทั้งหมด

## รายการตรวจข้ามระบบ

- จบบทจากบทสนทนา เดินถึงเป้าหมาย หรือ callback พร้อมกัน ต้องได้ transition เดียว
- ทดลองทุก eligible form กับ map seed หลายชุด ไม่ตรวจเฉพาะร่างเริ่มต้น
- ร่างบิน/มุด/ว่ายต้องมีทั้งจุดเกิดและทางออกที่รองรับ
- ออกจากเกมช่วงแสง ช่วงเลือก และช่วงลงสู่โลก แล้วโหลดกลับได้
- สลับภาษาไม่สุ่มผล เปลี่ยนโหมดไม่รีเซ็ตประวัติ
- แท็บซ่อน เกมหยุด และ reduced motion ให้ผลเรื่องราวเหมือนกัน
- พลาดแล้วมีทางกลับ ผู้เล่นไม่ต้องตายเพื่อ reroll ร่าง
- จบเส้นทางหลุดพ้นแล้วไม่มี rebirth callback ค้าง
- โหมดสำรวจไม่เขียนทับความคืบหน้าเนื้อเรื่อง
- เครื่องช้าลดอนุภาคได้โดยไม่เปลี่ยนโอกาสสุ่มหรือวิถีการเดิน

## ประเด็นของโค้ดที่ควรตรวจเพิ่ม

ระบบ candidates ปัจจุบันมีค่า maps เริ่มต้นครบทุกชนิดและมี fallback เป็นกวาง เมื่อเพิ่มโหมดสุ่มจริงควรส่งความสามารถแผนที่จริงและใช้คู่แผนที่–ร่างสำรองที่ตรวจแล้ว ไม่ถือว่า fallback ใด ๆ ปลอดภัยเสมอ

เอกสารเก่าบางแห่งยังบอกว่าสัตว์เพิ่มเป็น lab-only แต่โค้ดล่าสุดมีหลายตัวในเส้นทางเกิดใหม่แล้ว ให้ใช้ [รายการตรวจล่าสุด](animal-roster-audit.md) เป็นจุดอ้างอิงจนกว่าจะอัปเดตเอกสารเดิมครบ

## ไอเดียที่ควรพักไว้ก่อน

การผสมพันธุ์ร่าง ระบบอุปกรณ์จำนวนมาก เศรษฐกิจซื้อขาย multiplayer และโลกเปิดขนาดใหญ่ เพิ่มภาระก่อนวงจรหลักชัด ควรเริ่มหลังผู้เล่นสนุกกับสามชาติที่เชื่อมกันแล้ว
