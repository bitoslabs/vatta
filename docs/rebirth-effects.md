# เอฟเฟกต์ดวงจิต การตาย และเกิดใหม่

สถานะ: ข้อเสนอสำหรับพัฒนาต่อ ใช้ Canvas shapes, particles และเสียงสังเคราะห์หรือไฟล์เสียงที่ได้รับอนุญาต ไม่ใช้ภาพจาก ImageGen

## ภาษาภาพ

“ดวงจิต” ในเอกสารนี้คือชื่อเอฟเฟกต์แสงเพื่อเล่าเรื่องการเปลี่ยนชีวิต ไม่อ้างว่าเป็นดวงวิญญาณถาวรตามคำสอน ใช้จุดแสงอุ่นหนึ่งจุด วงแสงบาง และอนุภาค 12–24 จุด ไม่มีใบหน้าและไม่ต้องมีรูปร่างคนออกจากร่างสัตว์

สีสื่อสภาวะในฉาก ไม่จัดสีสัตว์เป็นดีหรือเลว: ทองอ่อน = สงบ, ฟ้า = ระลึกถึง, ม่วงหม่น = สับสน ใช้รูปทรงและเสียงร่วมด้วยเพื่อไม่พึ่งสีอย่างเดียว

## แยกการพลาดกับจบชีวิต

| เหตุการณ์ | ผลที่เสนอ |
|---|---|
| เดินพลาด/ถูกจับระหว่างด่าน | กลับจุดพัก เสียเวลาเล็กน้อย ไม่เปลี่ยนชาติและไม่ลดกรรมเพราะกดพลาด |
| จบเป้าหมาย chapter | จบชีวิตตามเรื่องราว เข้าสรุปแล้วเกิดใหม่ |
| ชีวิตสิ้นสุดตามบทเฉพาะ | ใช้ภาพสงบและคำบรรยายสั้น ไม่ต้องมีความรุนแรง |
| เลือกเริ่มด่านใหม่ | แยกเป็นเมนูเริ่มใหม่ ไม่ใช้การทำร้ายตัวเองเป็นทางลัดสุ่มร่าง |
| จบการเดินทาง | แสงค่อยนิ่ง ฉากคงอยู่ ไม่มีการสุ่มเกิดใหม่ |

## ลำดับภาพและเวลาเป้าหมาย

| ช่วง | เวลาเริ่มต้นสำหรับทดลอง | ภาพ/เสียง | ควบคุม |
|---|---|---|---|
| ยืนยันจบ | 0–0.25 วินาที | เงานิ่ง เสียงสิ่งแวดล้อมเบาลง | หยุดการโจมตีและการเคลื่อนที่ |
| ร่างสงบ | 0.25–0.8 วินาที | ย่อตัวหรือพัก ค่อยลดความทึบ | ข้ามได้หลังเห็นสัญญาณจบ |
| แสงรวม | 0.8–1.5 วินาที | แสงรวมเหนือจุดยืน วงขยายหนึ่งครั้ง | ไม่กระพริบขาวเต็มจอ |
| ร่องรอยชาติ | 1.5–2.5 วินาที | สัญลักษณ์เหตุการณ์สำคัญไม่เกิน 3 อย่าง เช่น เมล็ด สะพาน เพื่อน | กดอ่านรายละเอียดได้ |
| สรุป/ตัดสินร่าง | เริ่มนับ 5 วินาทีหลังภาพพร้อม | ชื่อร่างถัดไปและเหตุผล/โอกาสตามโหมด | พัก ข้าม หรือเลือก |
| ลงสู่โลก | 0.6–1 วินาที | แสงเคลื่อนไปจุดเกิด เงาค่อยชัด | โลกใหม่ต้องโหลดและตรวจเส้นทางเสร็จก่อน |
| เริ่มชีวิต | 0.5 วินาที | ร่างปรากฏ แสดงท่าหลักสั้น ๆ | คืนการควบคุมหลังวางร่างปลอดภัย |

ตัวเลขเป็นค่าเริ่มต้นเพื่อทดสอบ ไม่ใช่ข้อบังคับให้คัตซีนยาวทุกชาติ หลังเห็นครั้งแรกให้ย่อช่วงภาพได้ เหลือประมาณ 1–2 วินาทีก่อนหน้าสรุป

## เอฟเฟกต์เกิดตามร่าง

- สัตว์บก: แสงรวมใกล้พื้น เงาปรากฏก่อน ลุกยืนหรือขยับหู
- ใต้ดิน: หน้าตัดโพรงค่อยสว่าง ดินขยับเล็กน้อยแล้วร่างเคลื่อนออก
- สัตว์น้ำ: วงน้ำแผ่ออก ฟองอากาศไม่เกิน 8 จุด เกิดเฉพาะในน้ำที่ปลอดภัย
- สัตว์บิน: เงาอยู่บนจุดพัก ปีกค่อยคลาย ก่อนให้บินเอง
- เทวดา/นางฟ้า: เส้นแสงคลี่เป็นรูปทรงรอบตัว ไม่แฟลชแรง
- อสุร: ฝุ่นและรอยแสงพื้นเบา ๆ สื่อถึงน้ำหนักโดยไม่สั่นกล้องรุนแรง
- นาค: ระลอกน้ำไล่ตามลำตัว ส่วนหัวไม่เกิดติดขอบแผนที่

## สิ่งที่ส่งข้ามชีวิต

คงอยู่: ประวัติเหตุการณ์ ความสัมพันธ์ สิ่งที่โลกจำ บทเรียนที่ค้นพบ และร่างที่เคยพบ

เริ่มใหม่: ร่าง ตำแหน่ง พลังชั่วคราว cooldown และของที่ถือ ยกเว้นสิ่งที่เรื่องราวกำหนดไว้ชัดเจน

ห้ามเอาเอฟเฟกต์ความตายไปนับเป็นการกระทำทางศีลธรรมหรือเปลี่ยนผลร่างด้วยตัวเอง

## ข้อตกลงระบบ

สถานะที่เสนอ: PLAYING → ENDING → SUMMARY → RESOLVING → SPAWNING → PLAYING หรือ JOURNEY_COMPLETE

- ใช้ transitionId ประกอบจาก runId + lifeId + completionId ป้องกันเหตุการณ์จบซ้ำ
- จองผลร่างและ seed แผนที่ครั้งเดียวก่อนเริ่มฉากเกิด บันทึก pending transition
- โหลดกลับมาต้องได้ร่างเดิม; หากเซฟยังไม่สำเร็จให้แจ้งว่าเล่นต่อได้แต่ความคืบหน้าอาจไม่คงอยู่
- effect จบช้าหรือถูกข้ามก็ใช้ผลเดิม ไม่คำนวณการเกิดใหม่
- ระหว่าง SUMMARY/RESOLVING หยุด AI ความเสียหาย นาฬิกาด่าน และ input ของโลก
- คืน input หลัง spawn ผ่านการตรวจเท่านั้น ล้างปุ่มค้างจากฉากก่อน
- เปิดแท็บอื่นให้หยุดเวลาสรุป ไม่พาผู้เล่นข้ามชีวิตลับหลัง
- ตัวเลือก “ลดการเคลื่อนไหว” ใช้ fade สั้น ไม่มีอนุภาควิ่งหรือกล้องสั่น; มีข้อความแทนเสียง

## เกณฑ์ตรวจ

จบหนึ่งครั้งได้หนึ่งชีวิตใหม่, ข้ามเอฟเฟกต์แล้วผลไม่เปลี่ยน, โหลดทุกช่วงไม่ซ้ำชาติ, ปลาไม่เกิดบนบก, ร่างใหญ่ไม่ชนผนัง, ปุ่มสัมผัสไม่ค้าง, ปิดเสียง/ลดการเคลื่อนไหวยังเข้าใจเหตุการณ์, ฉากจบสุดท้ายไม่มี timer เรียกเกิดใหม่
