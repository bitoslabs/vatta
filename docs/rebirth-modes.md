# ระบบสุ่มเกิดและเลือกเกิด

## พฤติกรรมปัจจุบัน

ครบทั้งสามโหมด: **ตามกระแสชีวิต (flow)** · **ทางเลือกสามร่าง (choice)** · **สำรวจร่าง (explore)**

หลังจบด่าน ระบบแยกผลสองส่วน:

- **ภูมิ** คำนวณจากกรรมสะสมตลอดการเดินทาง: โทสะ → นรก, โลภะ → เปรต, โมหะ → เดรัจฉาน, ความยึดติด → อสุรกาย เมื่อแนวโน้มนั้นแรงกว่าฝ่ายกุศล หากเสมอกันให้ฝ่ายกุศลนำตามกติกาเกม สมาธิ เมตตา การให้ และสตินำไปสู่ภูมิตามเกณฑ์ใน `systems/rebirth.js` ภูมิมีผลต่อความเร็ว ความกลัว การมองเห็น และการตั้งสติ
- **ร่างที่เล่น** สุ่มจากร่างที่รองรับด่าน โดยคำนึงถึงความใหม่ ความเหมาะกับบท และการหลีกเลี่ยงสองร่างล่าสุด ชนิดสัตว์ไม่ได้ถูกกำหนดจากคะแนนกรรมโดยตรง ร่างและภูมิเป็นคนละกลไกในเกม

หน้าสรุปแสดงร่างถัดไป ภูมิ เหตุผลจากกรรม และโอกาสของร่างจริง ผลร่างและภูมิถูกจองพร้อมกันก่อนแสดงหน้าสรุป การดูตัวอย่างไม่ใช้ลำดับสุ่ม การจบซ้ำแม้เป็นคนละเหตุการณ์ไม่เปลี่ยนผล และการโหลดเซฟรักษาผลที่จองไว้ เซฟเก่าที่ไม่มีภูมิในรายการจองยังคำนวณจากกรรมที่บันทึกไว้ได้

โหมดเลือกสามร่างรอการเลือกและบันทึกทันที โหมดสำรวจร่างในหน้าเกิดใหม่เปิดสมุดให้เลือกเฉพาะร่างที่ด่านรองรับ เมื่อโหลดหน้าสรุปกลับมา ตัวจับเวลาจะทำงานต่อ และเมื่อเกิดใหม่สำเร็จจะบันทึกสถานะที่ไม่มีรายการเปลี่ยนชาติค้างอยู่

กฎต่อไปนี้เป็นข้อกำหนดการออกแบบและสูตรการสุ่ม:

## สามโหมดที่เสนอ

| โหมด | ผู้เล่นทำอะไร | เหมาะกับ | การเดินต่อ |
|---|---|---|---|
| ตามกระแสชีวิต | ระบบสุ่มหนึ่งร่างจากชุดที่ใช้กับด่านได้ | เนื้อเรื่องหลัก | สรุปแล้วเกิดใหม่อัตโนมัติ |
| ทางเลือกสามร่าง | เลือก 1 จาก 3 ร่างที่ระบบเตรียมให้ | ผู้เล่นที่อยากวางแผน | รอการเลือก ไม่ตัดสินใจแทนเมื่อหมดเวลา |
| สำรวจร่าง | เลือกร่างและด่านที่รองรับจากสมุดสัตว์ | ทดลองความสามารถ/โหมดครู | แยกเซฟจากความคืบหน้าเนื้อเรื่อง |

เลือกโหมดเมื่อเริ่มการเดินทาง เปลี่ยนผ่านตั้งค่าได้และเริ่มมีผลที่หน้าสรุปถัดไป การเปลี่ยนโหมดไม่ทำลายประวัติชาติที่ผ่านไปแล้ว

## กรองก่อนสุ่มหรือแสดงตัวเลือก

ร่างต้องมีข้อมูล ตัววาด ความสามารถ แผนที่ จุดเกิด เป้าหมาย และการตรวจเส้นทางรองรับ ห้ามยึดเพียง tags ว่า “อยู่บนบกได้” แล้วถือว่าทุกโจทย์ผ่านได้

ให้บทประกาศ mapCapabilities จริง เช่น land, water, burrow, air และภารกิจที่ต้องทำ ตรวจเงื่อนไขร่างกับโจทย์ทุกข้อ ไม่ส่งค่าเริ่มต้นว่ารองรับทุกพื้นที่เมื่อยังไม่ทราบ

หากกรองแล้วว่าง: ใช้คู่แผนที่–ร่างสำรองที่ตรวจแล้วสำหรับบทนั้น หากไม่มีให้พักหน้าเกิดใหม่พร้อมทางกลับและคำอธิบาย ไม่คืนกวางอัตโนมัติในแผนที่น้ำล้วน

## การสุ่มที่หลากหลายและตรวจสอบได้

ใช้ seeded PRNG แยกจาก RNG ที่ใช้วาดอนุภาค เริ่ม seed ต่อ run แล้วเก็บสถานะในเซฟ การโหลดซ้ำหรือกดเปิดหน้าสรุปต้องไม่สุ่มใหม่

สูตรตั้งต้นสำหรับทดลอง:

น้ำหนัก = น้ำหนักฐาน × ความใหม่ของร่าง × ความเหมาะกับเหตุการณ์

- น้ำหนักฐานเริ่มเท่ากันที่ 1
- ไม่เคยเป็นร่างนั้น: ×1.5; เคยเป็น: ×1
- ร่างในสองชาติล่าสุด: ตัดออกเมื่อยังมีตัวเลือกอื่น; ถ้าไม่เหลือ ใช้น้ำหนัก ×0.2
- มีเหตุการณ์เชื่อมกับร่าง: ×1.2 โดยเหตุการณ์ต้องแก้ได้ด้วยร่างนั้น
- normalize น้ำหนักให้รวมเป็น 100% และแสดงโอกาสจริงหาก UI บอกเปอร์เซ็นต์
- สัตว์หายากเพิ่มความแปลกใหม่ ไม่จำเป็นต้องเก่งกว่า และไม่ผูกกับการจ่ายเงินหรือรอรายวัน
- ไม่ตัดสินว่า “ทำไม่ดี = เกิดเป็นสัตว์ชนิดนี้” ความทรงจำเปลี่ยนเรื่องราว ไม่ลดคุณค่าของร่าง

ตัวอย่าง: กวางฐาน 1, เต่าใหม่ 1.5, ลิงตรงเหตุการณ์ 1.2 → โอกาสประมาณ 27.0%, 40.5%, 32.4% ก่อนใช้กฎร่างซ้ำ

## โหมดเลือก 3 ร่าง

สุ่มแบบไม่คืนตัวซ้ำจาก eligible pool แล้วบันทึก candidateIds ไว้ก่อนแสดง ชื่อ ภาพจากโค้ด ความสามารถหนึ่งบรรทัด และข้อจำกัดหนึ่งบรรทัดต้องเห็นพร้อมกัน

ตัวอย่าง “ป่าหลังฝน”: กวางใช้ทางกระโดด เต่าใช้ลำน้ำ ลิงใช้ทางต้นไม้ ทั้งสามไปถึงเป้าหมายเรื่องเดียวกันแต่พบเหตุการณ์ต่างกัน

หากมีเพียง 1–2 ร่างที่ผ่าน ให้แสดงตามจำนวนจริง ไม่แทรกร่างที่ใช้ไม่ได้ การยืนยันเป็นการเลือกร่างครั้งเดียว; ปุ่มย้อนดูรายละเอียดไม่สุ่มการ์ดใหม่ ผู้เล่นกด “สุ่มให้ฉัน” ได้โดยเลือกเฉพาะจากการ์ดที่เห็น

## ข้อมูลเซฟที่เสนอ

- rebirthMode: random / choice / explore
- runSeed, rebirthRngState และ algorithmVersion
- pendingTransition: transitionId, fromLifeId, nextChapterId, candidateIds, selectedFormId, mapSeed, phase
- history: ร่างที่เคยเป็นและจำนวนครั้ง
- encounterMemory: เหตุการณ์ที่ทำแล้วและผลที่ยังค้าง
- explorationSave: แยกออกจาก storySave

เซฟเก่าไม่มี field ใหม่ให้ใช้กฎเดิมต่อจนถึงหน้าสรุป แล้วเสนอให้เลือกโหมดครั้งเดียว ไม่เปลี่ยนร่างที่กำลังเล่นกลางด่าน

## กรณีที่ต้องกัน

กดเลือกสองครั้ง, timer และปุ่มทำงานพร้อมกัน, ปิดหน้าในจังหวะบันทึก, เปลี่ยนภาษาแล้วการ์ดสลับ, โหลดเซฟเวอร์ชันเก่า, ร่างถูกถอดจากเกม, maps ว่าง, RNG ถูกใช้โดย effect, chapter สุดท้ายเรียกเกิดใหม่หลังจบ

## เกณฑ์รับงาน

- seed และประวัติเหมือนกันได้ผลเดิม
- ไม่มีร่างไม่รองรับในผลสุ่มหรือการ์ด
- ไม่แสดงตัวซ้ำในสามการ์ด และจำนวนการ์ดตรงกับจำนวนที่มีจริง
- ทดสอบแจกแจงหลายพันครั้งเทียบช่วงความคลาดเคลื่อนที่กำหนด ไม่บังคับทุกชุดเล็กให้เท่ากัน
- ในโหมดเลือก ไม่มีการเกิดใหม่ก่อนเลือกหรือกด “สุ่มให้ฉัน”
- โหลดระหว่างเปลี่ยนชาติคงผลและเดินต่อได้
