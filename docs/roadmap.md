# แผนงาน / Roadmap

## บททั้งหมด (ภาค 1: 1–7 · ภาค 2: 8+)

| บท | ชื่อ | ธรรมหลัก | สถานะ | ผี / กลไก |
|---|---|---|---|---|
| 1 | ป่าเสียงเรียก | สติ | ✅ playable | ผีความกลัว — **SPACE ค้าง = ตั้งสติ**, ประตูแสงหลอก |
| 2 | ไฟในใจ | เมตตา · ไม่ตอบโต้ | ✅ playable | ผีโทสะ — **E = ตอบโต้ ทำให้โกรธขึ้น**, ไม่ตอบโต้ = มอด |
| 3 | ขุมทรัพย์กลางป่า | ตัณหา · โลภะ | ✅ playable | ผีโลภะ — วางของล่อ, **เก็บ = ยิ่งตามติด**, กด X วางของ, ไม่หยิบเลย = ผ่านสะอาด |
| 4 | ใครในกระจก | อนิจจัง | ✅ playable | ผียึดติด — ปลอมเป็นคนรัก, **เข้าใกล้/กอด = ยึด**, ยืนห่าง+สติ = ปล่อย |
| 5 | เสียงที่ไม่มีปาก | อนัตตา | ✅ playable | ผีตัวตน — ถาม "ใครหนี" ระหว่างทาง, ตอบยึดตัวเอง = เงาโต, เห็นเหตุปัจจัย = จาง |
| 6 | กงล้อ | อริยสัจ 4 | ✅ playable | 4 เฟสบนทางเดียว: ทุกข์ → สมุทัย (ของล่อ) → นิโรธ (สติ) → มรรค (เดินกลับ) |
| 7 | ทางพ้น | ศีล · สมาธิ · ปัญญา | ✅ playable | ไม่มีผี — 3 สถานี (ศีล/สมาธิ/ปัญญา) + ทางแยกสุดท้าย → นิพพาน ถ้ากรรมไม่ outweigh |
| 8 | กระจกแห่งกรรม | กรรม · เห็นตามจริง | ✅ playable | **ภาคสอง**: เงาที่เผชิญ = อนุสัยที่แรงสุดของเราเอง (โทสะ/โลภะ/โมหะ/อุปาทาน) — สงบด้วยการเห็น ไม่ใช่การสู้ |
| 9 | อนุสัยที่เหลือ | อนุสัย · รู้ทัน | ✅ playable | ผีที่ **เดินตามรอยเดิมของเจ้า** (replay) — กฎ/สี/สิ่งล่อเลือกจาก `karma.tendencies` ที่เหลือ |
| 10 | เงาที่โตขึ้น | การทำซ้ำ · รู้ทัน | ✅ playable | ผีที่ **โตขึ้นทุกครั้งที่ทำซ้ำ** (scale+speed) และ **หดลงเมื่อกด SPACE รู้ทัน** — เป้าหมาย: ไม่ทำซ้ำเลย |
| 11 | ผีคู่ | สองอนุสัย · รากเดียวกัน | ✅ playable | **ผีสองตัวพร้อมกัน** จากสองอนุสัยที่แรงสุด — ต้องเห็น “รากเดียวกัน” ทั้งคู่จึงจางพร้อมกัน |
| 12 | ผีที่แบ่งตัว | การกดข่ม · เห็นจากที่ห่าง | ✅ playable | **ยิ่งกดยิ่งเพิ่ม**: สติระยะใกล้ทำให้มันแบ่งตัว (สูงสุด 4) — ทางออกคือถอยห่างแล้วเห็นทั้งฝูงจางพร้อมกัน |
| 13 | เงาทั้งมวล | รวมทุกกลไกภาคสอง | ✅ playable | **บทส่งท้ายภาคสอง**: เปิดมาเป็นคู่, กดแล้วแบ่งตัว (สูงสุด 5), ทำซ้ำแล้วโต — จบด้วย distance + สติ และบทสรุปสองแบบตามกรรมสะสม |
| 14 | กงล้อและทางออก | ภาคสาม · ทางพ้น | ✅ playable | **บทส่งท้ายทั้งเกม**: กงล้อที่ทำลายไม่ได้ (คู่+แบ่งตัว+โต) — เดินผ่านถึงต้นโพธิ์ แล้ว **ทางออกถูก gate** ด้วย มรรค 8 ครบ + ศีล 5 ครบ + บุญ≥บาป → นิพพาน |

## งานถัดไป (เรียงตามความสำคัญ)

บทครบ 7 + กรรมเป็นความจำ + rebirth interlude + มรรค 8 + ศีล 5 เสร็จแล้ว — เหลือชั้นถัดไป:

1. **ต่อยอด "รอยทางข้ามภพ" ตามดีไซน์** (ดู docs/dynamic-samsara-design.md §12): ร่างสัตว์อีก 5 ชนิด (§5) · อสุร/เทวดา/นางฟ้า/มาร (§6) · แผนที่เฉพาะ (§7) · ลานกระจก/ฉากจบฉบับเต็ม (§8) · เป้าหมายเฉพาะร่างในทุกบท (ปลาไปตามลำน้ำ)
2. **ความสามารถเฉพาะร่างให้ลึกขึ้น**: กระโดดรากไม้ (กวาง) · อ่านกระแสน้ำ (ปลา) · สื่อสารด้วยท่าทางแทนบทสนทนา
3. **โหมดสำรวจหลังจบ**: ย้อนชมความทรงจำด้วยร่างที่ค้นพบ โดยไม่แก้ประวัติการเดินทางหลัก
3. **Asset จริง**: วางไฟล์ woff2 ใน `assets/fonts` แล้วเปิด `@font-face` (มีโครงไว้แล้ว) · เสียงที่บันทึกจริงแทน Web Audio · รูปภาพสำหรับฉาก


## หลักที่ต้องคงไว้

- คำสอนอยู่ใน **กลไก** ไม่ใช่ข้อความอ่านผ่าน
- ไม่มี "ถูก/ผิด" ลอย ๆ — โลกตอบสนอง ไม่ตัดสิน
- เจตนา (เจตนา) สำคัญกว่าผลลัพธ์เชิงแต้ม
- ไม่มีความตาย — มีแต่การเกิดใหม่ให้เรียนซ้ำ
