## งานถัดไป (เรียงตามความสำคัญ)

1. **บทที่ 3 — ผีโลภะ (ตัณหา)**
   - ไอเท็มล่อตามเส้นทาง (`content/lures.js`), เก็บแล้วกุศล/อกุศลตามเจตนา
   - วัดความโลภ: ยึดของไว้ → อนุสัย greed สูง → คติภูมิเปรต
2. **ระบบกรรมไม่ใช่คะแนน (จาก docs/chat.md ข้อ 9)**
   - `systems/karma.js` เก็บ `actions[]` แล้วดึงกลับมาเป็นเหตุการณ์: บทหลังเจอตัวละครที่ "จำ" สิ่งที่เราเคยทำ
3. **ฉากรับผลกรรมกลางเกม (rebirth interlude)**
   - เมื่อถูกกลืน/ตาย ให้เห็นภูมิชั่วครู่ก่อนเกิดใหม่ แทน respawn ธรรมดา
4. **มรรค 8 เป็น skill tree แบบ "เปิดวิธีมองโลก"** ไม่ใช่ตัวเลขดาเมจ
5. **ศีล 5 เป็น choice system** ที่ไม่ตัดสินถูกผิด แต่โลกจำและสะท้อนกลับ
6. **บทที่ 3–6 ต่อด้วย palette / กฎ / ผี ใหม่** (โครงพร้อมแล้ว: เพิ่ม entry + story + locale)
7. **Asset จริง (ถ้าต้องการ)**: `assets/fonts` (ฝังฟอนต์ออฟไลน์), `assets/audio` (แทน Web Audio), `assets/images`

## หลักที่ต้องคงไว้

- คำสอนอยู่ใน **กลไก** ไม่ใช่ข้อความอ่านผ่าน
- ไม่มี "ถูก/ผิด" ลอย ๆ — โลกตอบสนอง ไม่ตัดสิน
- เจตนา (เจตนา) สำคัญกว่าผลลัพธ์เชิงแต้ม
- ไม่มีความตาย — มีแต่การเกิดใหม่ให้เรียนซ้ำ
