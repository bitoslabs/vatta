# แผนงาน / Roadmap

## บททั้ง 7 (ตามอริยสัจ 4 และหลักธรรมที่ไล่ระดับ)

| บท | ชื่อ | ธรรมหลัก | สถานะ | ผี / กลไก |
|---|---|---|---|---|
| 1 | ป่าเสียงเรียก | สติ | ✅ playable | ผีความกลัว — **SPACE ค้าง = ตั้งสติ**, ประตูแสงหลอก |
| 2 | ไฟในใจ | เมตตา · ไม่ตอบโต้ | ✅ playable | ผีโทสะ — **E = ตอบโต้ ทำให้โกรธขึ้น**, ไม่ตอบโต้ = มอด |
| 3 | ขุมทรัพย์กลางป่า | ตัณหา · โลภะ | ✅ playable | ผีโลภะ — วางของล่อ, **เก็บ = ยิ่งตามติด**, กด X วางของ, ไม่หยิบเลย = ผ่านสะอาด |
| 4 | ใครในกระจก | อนิจจัง | ✅ playable | ผียึดติด — ปลอมเป็นคนรัก, **เข้าใกล้/กอด = ยึด**, ยืนห่าง+สติ = ปล่อย |
| 5 | เสียงที่ไม่มีปาก | อนัตตา | ✅ playable | ผีตัวตน — ถาม "ใครหนี" ระหว่างทาง, ตอบยึดตัวเอง = เงาโต, เห็นเหตุปัจจัย = จาง |
| 6 | กงล้อ | อริยสัจ 4 | ✅ playable | 4 เฟสบนทางเดียว: ทุกข์ → สมุทัย (ของล่อ) → นิโรธ (สติ) → มรรค (เดินกลับ) |
| 7 | ทางพ้น | ศีล · สมาธิ · ปัญญา | ✅ playable | ไม่มีผี — 3 สถานี (ศีล/สมาธิ/ปัญญา) + ทางแยกสุดท้าย → นิพพาน ถ้ากรรมไม่ outweigh |

## งานถัดไป (เรียงตามความสำคัญ)

บทครบ 7 แล้ว (playable ทั้งหมด) — งานต่อไปคือชั้นที่ลึกกว่าเกมเพลย์:

1. **ระบบกรรมไม่ใช่คะแนน (จาก docs/chat.md ข้อ 9)**
   - `karma.actions[]` ถูกเก็บอยู่แล้ว — ดึงกลับมาเป็นเหตุการณ์: บทหลังเจอตัวละคร/เหตุการณ์ที่ "จำ" สิ่งที่เราเคยทำ
2. **ฉากรับผลกรรมกลางเกม (rebirth interlude)**
   - เมื่อถูกกลืน/ตาย ให้เห็นภูมิชั่วครู่ (การ์ดคติภูมิ) ก่อนเกิดใหม่ แทน respawn ธรรมดา
3. **มรรค 8 เป็น skill tree แบบ "เปิดวิธีมองโลก"** ไม่ใช่ตัวเลขดาเมจ
4. **ศีล 5 เป็น choice system** ที่ไม่ตัดสินถูกผิด แต่โลกจำและสะท้อนกลับ
5. **โหมดครู/ห้องเรียน**: ปิดผี เปิดเดินชมภูมิ พร้อมคำบรรยาย (ดู docs/samsara.md §5.ค)
6. **Asset จริง (ถ้าต้องการ)**: `assets/fonts` (ฝังฟอนต์ออฟไลน์), `assets/audio` (แทน Web Audio), `assets/images`

## หลักที่ต้องคงไว้

- คำสอนอยู่ใน **กลไก** ไม่ใช่ข้อความอ่านผ่าน
- ไม่มี "ถูก/ผิด" ลอย ๆ — โลกตอบสนอง ไม่ตัดสิน
- เจตนา (เจตนา) สำคัญกว่าผลลัพธ์เชิงแต้ม
- ไม่มีความตาย — มีแต่การเกิดใหม่ให้เรียนซ้ำ
